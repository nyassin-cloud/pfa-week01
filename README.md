# pfa-week01
Maya Python scripts for Programming for Animators.
This tool helps create a falling snow effect using an image uploaded directly through the script. The user can adjust the amount of snow planes, the width of the area where the snow falls, the falling speed, and other settings.
Run the tool from the terminal in Maya using python 
I would change it by adding different motion settings so the user could choose between snow, rain, ash, leaves, and other falling effects. I would also add a setting that lets the effect interact with objects already in the scene, so snow could build up on their surfaces.
